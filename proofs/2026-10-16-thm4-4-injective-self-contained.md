## 1. Setup and definitions

- k = Q(q). I is a finite Cartan datum with symmetrised form (α_i,α_j) = d_i a_ij.
- 'f = free algebra on F_i (i∈I), with |F_i| = α_i.
  - 'f is the tensor algebra T(V) on V = span F_i in C_q, with F_i primitive. It is a connected braided bialgebra in C_q.
  - Its coproduct r is the algebra map to the braided tensor product with r(F_i) = F_i⊗1+1⊗F_i. This is Lusztig's r of 1.2.2, and also the standard tensor-algebra structure in a braided category.
- **Θ** (quantum shuffle map): Θ = π∘Ψ_0^{'f}, where Ψ_0^{'f} is the Thm 2 map for 'f with φ=0 and ζ(F_i)=1.
  - π: QSym_{q,φ} → Sh_q(V) kills every M_α having a letter that is not a simple root.
  - π is a bialgebra map, and its target Sh_q(V) is the quantum shuffle algebra (proof of Thm 4(4) in the Day 241 file):
    - Merges only raise heights, so the kernel is an ideal.
    - Deconcatenation keeps a bad letter on one side, so it is a coideal.
    - Merges of simple letters are non-simple, so the quotient product is the shuffle with crossing weights q^{(v-letter, u-letter)}.
  - By Lemma A,
    Θ(x) = Σ_w c_w(x) [w_1|…|w_n], where π_w r^{(n−1)}(x) = c_w(x) F_{w_1}⊗…⊗F_{w_n}.
  - Θ is an algebra map (Thm 2, π) and a coalgebra map into T^c(V) with deconcatenation. Θ(F_i) = [i], so Θ(F_{w_1}⋯F_{w_n}) = [w_1]ш…ш[w_n].
- **f := 'f / ker Θ.**
  - ker Θ is an ideal because Θ is an algebra map.
  - It is a coideal: if Θx=0 then (Θ⊗Θ)r(x) = ΔΘ(x) = 0, so r(x) ∈ ker Θ⊗'f + 'f⊗ker Θ.
  - So f is a connected braided bialgebra in C_q, and Thm 2 applies to it. This is the Nichols algebra B(V) of the diagonal braiding q^{(α_i,α_j)}.
  - The dictionary with Lusztig's f = 'f/rad is Lemma D (§4, proved without citation in cycle 2). Nothing in §2–3 uses it.
- **Notation.** D_t is the algebra automorphism F_i ↦ t_iF_i of 'f, for t ∈ (k^×)^I. Θ(D_t x) = t^ν Θ(x) for x ∈ 'f_ν, so D_t preserves ker Θ and descends to an automorphism of f.

## 2. Injectivity (no citation)

**Lemma 1.** For every bilinear φ and every t ∈ k^I, the free-algebra map Ψ_φ^{'f} (with ζ(F_i) = t_i) satisfies π∘Ψ_φ^{'f} = Θ∘D_t. In particular, π∘Ψ_φ does not depend on φ.

*Proof.*
- By Lemma A, the coefficient of M_w for a simple-letter word w is Π_k ζ_{α_{w_k}}(π_w r^{(n−1)}x).
- Each tensor factor lies in 'f_{α_i} = kF_i, and ζ(F_i) = t_i. So the coefficient is t^ν c_w(x) = c_w(D_t x) for x ∈ 'f_ν.
- φ enters only through ζ on 'f_λ with ht λ ≥ 2, and those letters are killed by π. ∎

**Theorem 4(4)(a) (injectivity).** Let φ be bilinear and t ∈ (k^×)^I. Suppose a φ-character ζ: f → A_φ with ζ(F_i) = t_i exists. Then Ψ_φ^f: f → QSym_{q,φ} is injective.

*Proof.*
- Let p: 'f → f be the quotient map. Then ζ∘p is a φ-character of 'f, and Ψ_φ^f∘p is a graded coalgebra map 'f → QSym with ζ_Q∘Ψ_φ^f∘p = ζ∘p.
- By uniqueness in Lemma A, Ψ_φ^f∘p = Ψ_φ^{'f}.
- Suppose Ψ_φ^f(p(x)) = 0. Then Θ(D_t x) = π Ψ_φ^{'f}(x) = 0 by Lemma 1. So D_t x ∈ ker Θ, hence x ∈ ker Θ (D_t^{-1} preserves ker Θ), hence p(x) = 0. ∎

Conversely, injectivity forces every t_i ≠ 0, since Ψ_φ(F_i) = t_i M_{α_i}.

## 3. Existence for the forced twist: the sorted-word character

**Lemma 2 (sorted-word character).** Fix a total order o on I. Define the linear functional λ_o on Sh_q(V) by
  λ_o([w]) = Π_{i∈I} 1/[n_i]_{q_ii}!  if w is weakly increasing for o (n_i = number of i's in w; q_ii = q^{(α_i,α_i)}; [n]_z! = Π_{m≤n}(1+z+…+z^{m−1})),
  λ_o([w]) = 0 otherwise.
Then λ_o is a φ_o-character of Sh_q(V), i.e. λ_o(XшY) = q^{φ_o(|X|,|Y|)} λ_o(X)λ_o(Y), where

  φ_o(α_k, α_l) = (α_k, α_l) if k comes after l in o, and 0 otherwise (diagonal 0).

*Proof.*
- By bilinearity it suffices to take words u, v.
- If λ_o(uшv) ≠ 0, some sorted word s occurs in uшv. Then u and v are subsequences of s, hence sorted. So if u or v is unsorted, both sides vanish.
- Let u, v be sorted, with contents (a_i), (b_i). The only sorted word in uшv is s, with content a_i+b_i. Its coefficient is a sum over shuffles that interleave the letters within each block of equal letters. Blocks appear in o-order.
- *Inside block i:* each v-letter placed before a u-letter gives q^{(α_i,α_i)} = q_ii. Summing q_ii^{#inversions} over the C(a_i+b_i, a_i) interleavings gives the Gaussian binomial [a_i+b_i, a_i]_{q_ii}.
- *Across blocks l <_o k:* every v-letter of block l is placed before every u-letter of block k, so the weight is q^{b_l a_k (α_l, α_k)}. Pairs (u in l, v in k) don't cross.
- So λ_o(uшv) = Π_i [a_i+b_i, a_i]_{q_ii}/[a_i+b_i]_{q_ii}! · q^{Σ_{l<_o k} b_l a_k (α_l,α_k)} = q^{φ_o(|u|,|v|)} λ_o(u)λ_o(v).
  - Here φ_o(|u|,|v|) = Σ_{k,l} a_k b_l φ_o(α_k,α_l) = Σ_{k >_o l} a_k b_l (α_k,α_l). ∎

**Theorem 4(4)(b) (existence).** Let g be of finite type (or any Cartan datum whose Dynkin graph is a forest). Let φ be bilinear with
- φ(α_i,α_j) − φ(α_j,α_i) = ±(α_i,α_j) on every edge, and
- φ symmetric on non-edges (the forced twist of Thm 4(2)).

Then for **every** t ∈ (k^×)^I there is a φ-character ζ: f → A_φ with ζ(F_i) = t_i.

*Proof.*
1. *Orientation and order.* Orient each edge {k,l} as k→l when φ(α_k,α_l) − φ(α_l,α_k) = −(α_k,α_l).
   - Any orientation of a forest is acyclic, so it has a linear extension o.
   - φ_o has antisymmetric part φ_o(α_k,α_l) − φ_o(α_l,α_k) = −(α_k,α_l) for k <_o l. On edges this matches φ. On non-edges both sides are 0.
   - So σ := φ − φ_o is symmetric.
2. *Absorbing σ.* Put Q(ν) = Σ_{k<l} σ_kl ν_kν_l + Σ_k σ_kk C(ν_k, 2), which is integer-valued.
   - Then Q(λ+μ) − Q(λ) − Q(μ) = σ(λ,μ), and Q(α_i) = 0.
3. *The character.* Define ζ on 'f by ζ(x) = q^{Q(ν)} λ_o(Θ(D_t x)) for x ∈ 'f_ν.
   - Θ∘D_t is an algebra map and λ_o is a φ_o-character (Lemma 2). So ζ(xy) = q^{Q(λ+μ)} q^{φ_o(λ,μ)} λ_oΘD_t(x) λ_oΘD_t(y) = q^{σ(λ,μ)+φ_o(λ,μ)} ζ(x)ζ(y) = q^{φ(λ,μ)}ζ(x)ζ(y).
   - Also ζ(F_i) = t_i λ_o([i]) = t_i.
4. *Descent.* ζ vanishes on ker Θ, because D_t preserves ker Θ. So ζ descends to f. ∎

**Corollary (exactly when).** Let g be of finite type and t ∈ (k^×)^I. Then Ψ_φ: f → QSym_{q,φ} exists and is injective **iff** φ is a forced twist.
- (⇐) is 4(4)(b) plus 4(4)(a).
- (⇒) is Thm 4(2). Its input is that the q-Serre elements vanish in f, i.e. Θ(ad_c(F_i)^{1−a_ij}F_j) = 0. This is now verified **symbolically in q** for every finite rank-2 type A1×A1, A2, B2, G2, in both directions (`shuffle_checks.py`, 8/8).
  - This is a finite identity check in Q(q), hence a proof for finite type: every pair i≠j spans one of these four.
  - No appeal to Lusztig 1.4.3 or 33.1.3 is needed.
  - The Thm 4(1) Serre-value formula itself is now verified **symbolically in q, t_i and all four φ-entries** for every finite rank-2 type in both directions, including G2 with n=4 (`thm41_check.py`, 8/8). This closes Day 241 gap 2, where "G2 not computed" and the ad_c^n expansion had been checked only for n≤3.

**Remarks.**
- The proof of (b) also shows ζ is *the coefficient of the o-sorted word in the quantum shuffle image*, rescaled. A φ-character of f is read off one word.
- Two linear extensions of the same orientation give the same ζ, since a φ-character is determined by t. This was checked: o = (0,2,1) vs (2,0,1), with 0 failures.
- The forest hypothesis enters only in step 1. For a Dynkin graph with a cycle (affine Ã_n, n≥2) and a **cyclic** orientation, no linear extension exists, and whether a φ-character with all t_i ≠ 0 exists there is open (not pursued: no new problems).
- Where q enters: [n]_{q_ii}! ≠ 0 in λ_o, so q must not be a root of unity of small order. Over Q(q) this is automatic.

## 4. Dictionary with Lusztig (Lemma D — proved in cycle 2, Lusztig 1.2.3 no longer cited)

**Conventions (definitions, not theorems).** Lusztig's r: 'f → 'f⊗'f is the algebra map with r(F_i) = F_i⊗1 + 1⊗F_i, where the product on 'f⊗'f is
(x1⊗x2)(y1⊗y2) = v^{(|x2|,|y1|)} x1y1⊗x2y2 (1.2.2). With q = v, this is our braided tensor product in C_q. Lusztig's form is a bilinear form ( , ) on 'f with
- (a) (1,1) = 1, and (F_i,F_j) = δ_ij κ_i, where κ_i = (1−v_i^{−2})^{−1} and v_i = v^{d_i};
- (b) (x, y'y'') = (r(x), y'⊗y''), where (x1⊗x2, y1⊗y2) := (x1,y1)(x2,y2);
- (c) (x'x'', y) = (x'⊗x'', r(y)).

f is by definition 'f/rad (1.2.5). Lusztig proves (1.2.3) that such a form exists, is unique and is symmetric. Here all three facts are re-derived, so nothing is cited.
(If a reader's r uses v^{−(|x2|,|y1|)}, the same proof applies with q ↦ q^{−1}. Nothing below depends on the sign.)

**Notation.** For a word w = w_1…w_n, put κ_w = Π_k κ_{w_k} and F_w = F_{w_1}⋯F_{w_n}. The coefficient c_w(x) is the one from §1: π_w r^{(n−1)}(x) = c_w(x) F_{w_1}⊗…⊗F_{w_n}.

**Definition.** B(x, F_w) := κ_w c_w(x). The words F_w form a basis of 'f, so this extends to a unique bilinear form B on 'f×'f.

**Lemma D.**
- (i) B satisfies (a), (b) and the weight orthogonality 'f_ν ⊥ 'f_μ (ν ≠ μ).
- (ii) Any form satisfying (a) and (b) equals B. Hence Lusztig's form exists, is unique, and equals B.
- (iii) B is symmetric. Hence (c) also holds.
- (iv) rad B = ker Θ. Hence Lusztig's f = 'f/ker Θ = our f.

*Proof.*

(i)
- *Orthogonality:* r is graded, so c_w(x) = 0 for x ∈ 'f_ν unless content(w) = ν.
- *(a):* c_∅(1) = 1, and c_j(F_i) = δ_ij. So B(F_i, F_j) = δ_ij κ_i.
- *(b):* by bilinearity, take y' = F_a and y'' = F_b to be words, with |a| = m and |b| = n−m ≥ 1. Coassociativity gives r^{(n−1)} = (r^{(m−1)} ⊗ r^{(n−m−1)})∘r as linear maps; no braiding enters, since only tensor factors are being regrouped. The component π_{ab} factors as π_a ⊗ π_b. So, writing r(x) = Σ x_(1)⊗x_(2),
  c_{ab}(x) = Σ c_a(x_(1)) c_b(x_(2)).
  Multiplying by κ_{ab} = κ_aκ_b gives B(x, F_aF_b) = Σ B(x_(1),F_a) B(x_(2),F_b) = (r(x), F_a⊗F_b)_B.
  (The cases m = 0 or n are trivial, because r(x) has the components x⊗1 and 1⊗x.)

(ii) Let ( , ) satisfy (a) and (b). Peel off the first letter: (x, F_w) = (r(x), F_{w_1}⊗F_{w_2…w_n}). Induction on n then gives (x, F_w) = (r^{(n−1)}x, F_{w_1}⊗…⊗F_{w_n}).
- One more input is needed: (a) and (b) force orthogonality of weight spaces, i.e. (x, F_w) = 0 for x ∈ 'f_ν with ν ≠ content(w). This follows by the same induction: r^{(n−1)}x has components of degrees (λ_1,…,λ_n) with Σλ_k = ν, and the base case is (x, F_i) for x ∈ 'f_λ.
- Base case. For λ = α_i, x is a multiple of F_i and (a) applies.
- For λ = 0 there is no base case: (a)+(b) do **not** force (1, F_i) = 0.
  - For example, (1, F_i·1) = (r(1), F_i⊗1) = (1, F_i) is a tautology.
  - Setting (1, F_w) = Π_k c_{w_k}, with arbitrary scalars c_i, and extending by (b) gives a non-graded family.
- So uniqueness needs the orthogonality axiom (o): 'f_ν ⊥ 'f_μ for ν ≠ μ. Lusztig's form has it, since his construction is degree by degree.
- Given (a)+(b)+(o): only the component of r^{(n−1)}x in 'f_{α_{w_1}}⊗…⊗'f_{α_{w_n}} = kF_{w_1}⊗…⊗kF_{w_n} contributes. That component is c_w(x)F_{w_1}⊗…, so (x, F_w) = κ_w c_w(x) = B(x, F_w).
- B satisfies (o) by (i). So whichever axiom list one takes for Lusztig's form ((a)+(b)+(o), or (a)–(c), each of which implies (o) on the relevant side), the form equals B.

(iii) It suffices to check words: c_w(F_u) = c_u(F_w), with κ_u = κ_w (equal content; otherwise both sides are 0).
- Θ is an algebra map, so c_w(F_u) = coefficient of [w] in [u_1]ш…ш[u_n].
- Iterating the two-word shuffle, this is Σ_σ q^{e(σ)}. The sum runs over permutations σ ∈ S_n with w_{σ(k)} = u_k (letter u_k is placed in slot σ(k)). The exponent is e(σ) = Σ_{k<l, σ(k)>σ(l)} (α_{u_k}, α_{u_l}): each inversion is a later letter jumping an earlier one and pays the form on the pair. (Induct on n: [u_1…u_{n−1}-shuffle]ш[u_n] places u_n and pays (α_{u_n}, α_{x}) for every earlier letter x it precedes. These are exactly the inversions involving n.)
- σ ↦ σ^{−1} is a bijection {σ : w∘σ = u} → {τ : u∘τ = w}. An inversion (k,l) of σ corresponds to the inversion (σ(l), σ(k)) of σ^{−1}. Its letters are w_{σ(l)} = u_l and w_{σ(k)} = u_k, paying (α_{u_l}, α_{u_k}).
- (·,·) is symmetric, so e(σ^{−1}) = e(σ), and therefore c_w(F_u) = c_u(F_w).
- (c) now follows: (x'x'', y) = (y, x'x'') = (r(y), x'⊗x'') = (x'⊗x'', r(y)), using symmetry of B and hence of the factorwise form.

(iv)
- Since κ_w ≠ 0 (over Q(q), v_i^{−2} ≠ 1), x lies in the left radical iff c_w(x) = 0 for all w iff Θ(x) = 0.
- B is symmetric, so the left radical = the right radical = rad. ∎

**Status:** proved (no citation). The only Lusztig input is the *definition* of r and of f = 'f/rad.
Note on (ii): (a)+(b) alone do not pin (1, F_i). Lusztig's construction gives grading orthogonality, and any reasonable reading of 1.2.3 includes it. Either way the form is B.
