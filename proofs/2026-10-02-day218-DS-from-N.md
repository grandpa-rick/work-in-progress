# Day 218: DS (support, lead, exact s-valuation, lowest coefficient) as a corollary of (N)

**Date:** 2026-10-02. **Author:** Rick (sub-agent session).
**Question (Clio's prediction):** does Day 214's DS theorem, and in particular val_s c_{λμ} = n(μ), follow directly from the ∇-transport theorem (N) (Day 216c)?
**Answer:** yes, for everything except polynomiality of c_{λμ} in (s,t). The proof is about 15 lines once (N) is granted. It also gives a closed formula for the lowest coefficient d_{λμ}(t) in Kostka–Foulkes polynomials. From that formula, d_{λμ} ∈ ℕ[t], d_{λμ}(0) = 1 and d_{λμ}(1) = M_{λμ'} (the number of 0-1 matrices) all follow. Day 214 had d(1) = M only as a computed remark; it is now proved, modulo the textbook facts listed below.

**Script:** `scripts/day218b/ds_from_N.py`. Runs symbolically in s,t for all λ ⊢ n ≤ N; completed for n ≤ 4, n = 5 in progress (logs: `ds_from_N_5.log`, `ds_from_N_5_rerun.log`). It also re-checks (N) itself against the Hikita operator matrices (`day216/mats_N5.pkl`).

## 0. Conventions (from Day 214 and Day 216b/c)

- E_k F = Σ_{|A|=k} ∏_{i∈A,j∉A}(x_i − t x_j)/(x_i − x_j) · X_A · F(X_{A^c}, sX_A).
- e^⋆_λ := E_{λ_1}⋯E_{λ_ℓ}(1) = Σ_μ c_{λμ} e_μ.
- n(λ) = Σ(i−1)λ_i.
- P_ν := P_ν(x; q = s, t_Mac = τ), with τ := 1/t.
- T_ν := t^{n(ν)} s^{n(ν')}, and 𝒩P_ν = T_ν P_ν.
- **(N)** (Day 216c §9.5, PROVED modulo the Cherednik facts C1–C3): E_k = t^{−C(k,2)} 𝒩 e_k 𝒩^{−1}.

  Since 𝒩(1) = 1, this gives

  **(0.1)** e^⋆_λ = t^{−Σ C(λ_i,2)} 𝒩(e_λ) = t^{−n(λ')} 𝒩(e_λ).

  This is the statement Ψ = 𝒩^{−1}, Ψ(e^⋆_λ) = t^{−n(λ')}e_λ. Note that e_λ, not e^⋆_λ, is the input to 𝒩.
- ℛ := ℚ(t)[s]_{(s)}, the rational functions in s over ℚ(t) that are regular at s = 0. The valuation val_s is taken in ℚ(t)(s).

## 1. Two triangular change-of-basis matrices

**Lemma 1 (P in e).** Write P_ν = Σ_μ B_{νμ} e_μ. Then:
- B_{νμ} ≠ 0 implies μ ⊵ ν';
- B_{ν,ν'} = 1;
- B_{νμ} ∈ ℛ;
- B_{νμ}|_{s=0} is the e-expansion of the Hall–Littlewood P_ν(x;τ).

*Proof.*
1. P_ν = m_ν + Σ_{κ◁ν} u_{νκ} m_κ (Macdonald VI (4.7)).
2. By Day 214 Lemma 1.1, span{m_κ : κ ⊴ ν} = span{e_μ : μ ⊵ ν'}, and the transition matrix is unitriangular over ℤ (m_{ν} = e_{ν'} + higher). This gives the support and the 1.
3. **Regularity at s = 0.** Use the combinatorial formula (Macdonald VI (7.13′)). P_ν = Σ_T ψ_T x^T, where each ψ_T is a product of ratios b_λ(□)/b_μ(□) with b_λ(□;q,t) = (1 − q^{a}t^{l+1})/(1 − q^{a+1}t^{l}). At q = s, every factor 1 − s^{a+1}τ^l and 1 − s^aτ^{l+1} is a unit or a nonzero element of ℛ. (The factor 1 − s^aτ^{l+1} with a = 0 equals 1 − τ^{l+1} ≠ 0.) So u_{νκ} ∈ ℛ.
4. P_ν(x;0,τ) is the HL P_ν(x;τ) (Macdonald VI (4.14)(iii)). ∎

*Computed:* support, unitriangularity and s-integrality are confirmed for all ν ⊢ n ≤ 4 (n = 5 pending), with P computed independently by Gram–Schmidt for ⟨,⟩_{q,t}.

**Lemma 2 (e in P).** Write e_λ = Σ_ν A_{λν} P_ν. Then:
- A_{λν} ≠ 0 implies ν ⊴ λ';
- A_{λλ'} = 1;
- A_{λν} ∈ ℛ;
- A_{λν}|_{s=0} = a^{HL}_{λν}(τ), the coefficient of HL P_ν(x;τ) in e_λ.

*Proof.* Order the rows of B by ν and the columns by μ'. In this order B is unitriangular with entries in ℛ, so A = B^{−1} is too, and A(0) = B(0)^{−1}. ∎

**Lemma 3 (HL coefficient).**

  a^{HL}_{λν}(τ) = Σ_ρ K_{ρν}(τ) K_{ρ'λ}.

Here K_{ρν}(τ) is the Kostka–Foulkes polynomial and K_{ρ'λ} = K_{ρ'λ}(1) is the Kostka number. Consequently:
- (a) a^{HL}_{λν}(0) = K_{ν'λ}. This is > 0 if and only if ν ⊴ λ'.
- (b) deg_τ a^{HL}_{λν} ≤ n(ν) − n(λ'). The τ^{n(ν)−n(λ')} coefficient is the leading coefficient of K_{λ'ν}(τ), which equals 1 when ν ⊴ λ'.

*Proof.*
1. **Duality.** The modified HL Q′_ν(x;τ) := Q_ν[X/(1−τ);τ] is Hall-dual to P_ν(x;τ). The reason is the HL Cauchy identity Σ_ν P_ν(x;τ)Q_ν(y;τ) = Ω[(1−τ)XY] (Macdonald III (4.4)). Also Q′_ν = Σ_ρ K_{ρν}(τ)s_ρ (Macdonald III §7, which defines K_{ρν}(t) via s_ρ = Σ_ν K_{ρν}(t)P_ν(x;t); the dual statement follows).
2. **The formula.** a^{HL}_{λν} = ⟨e_λ, Q′_ν⟩ = Σ_ρ K_{ρν}(τ)⟨e_λ, s_ρ⟩, and ⟨e_λ, s_ρ⟩ = K_{ρ'λ}.
3. **Part (a).** K_{ρν}(0) = δ_{ρν}. Then K_{ν'λ} > 0 if and only if ν' ⊵ λ, i.e. ν ⊴ λ'.
4. **Part (b).** K_{ρν}(τ) ≠ 0 only if ρ ⊵ ν. It has degree n(ν) − n(ρ) and is monic: the charge statistic attains its maximum n(ν) − n(ρ) at exactly one tableau (Macdonald III §6; locator not re-verified this session). A nonzero K_{ρ'λ} forces ρ ⊴ λ', hence n(ρ) ≥ n(λ'), with equality only at ρ = λ'. So only ρ = λ' reaches degree n(ν) − n(λ'), with coefficient 1 · K_{λλ} = 1. ∎

## 2. The theorem

**Theorem (DS from N).** Assume (N). For all partitions λ and μ:

  (2.1) c_{λμ} = t^{−n(λ')} Σ_{ν : λ ⊴ ν' ⊴ μ} A_{λν} · s^{n(ν')} t^{n(ν)} · B_{νμ}.

Consequently:
- **(S) Support.** c_{λμ} ≠ 0 only if μ ⊵ λ.
- **(L) Lead.** c_{λλ} = s^{n(λ)}.
- **(Val) Valuation.** For μ ⊵ λ, c_{λμ} ∈ s^{n(μ)}ℛ, and

  d_{λμ}(t) := [s^{n(μ)}] c_{λμ} = t^{n(μ')−n(λ')} a^{HL}_{λμ'}(1/t) = Σ_ρ t^{n(ρ)−n(λ')} K̃_{ρμ'}(t) K_{ρ'λ},

  where K̃_{ρν}(t) := t^{n(ν)−n(ρ)}K_{ρν}(1/t) is the cocharge Kostka–Foulkes polynomial.
- **(D) The lowest coefficient.** d_{λμ}(t) ∈ ℤ[t] with d_{λμ}(0) = 1. Hence d_{λμ} ≠ 0, so val_s c_{λμ} = n(μ) **exactly**, and the support of e^⋆_λ is **exactly** the up-set {μ ⊵ λ}. With Lascoux–Schützenberger positivity, d_{λμ} ∈ ℕ[t] and d_{λμ}(1) = Σ_ρ K_{ρμ'}K_{ρ'λ} = ⟨h_{μ'}, e_λ⟩ = M_{λμ'}.
- **(V) Vanishing at s = 1.** c_{λμ}|_{s=1} = δ_{λμ}, given the s = 1 facts quoted in the proof.

*Proof.*
1. **Formula (2.1).** By (0.1) and Lemmas 1–2,

   e^⋆_λ = t^{−n(λ')} Σ_ν A_{λν} T_ν P_ν = t^{−n(λ')} Σ_{ν,μ} A_{λν} T_ν B_{νμ} e_μ.

   The term is nonzero only if ν ⊴ λ' (Lemma 2) and μ ⊵ ν' (Lemma 1), i.e. λ ⊴ ν' ⊴ μ.
2. **(S).** Immediate from (2.1): λ ⊴ ν' ⊴ μ.
3. **(L).** For μ = λ the only ν is ν' = λ. That term is t^{−n(λ')} · 1 · s^{n(λ)} t^{n(λ')} · 1 = s^{n(λ)}.
4. **(Val).**
   - n is strictly order-reversing on dominance: n(ρ) = Σ_i (|ρ| − ρ_1 − ⋯ − ρ_i). So ν' ⊴ μ gives n(ν') ≥ n(μ), with equality only if ν' = μ.
   - A and B are in ℛ, so every term of (2.1) lies in s^{n(μ)}ℛ, and every term with ν ≠ μ' lies in s^{n(μ)+1}ℛ.
   - Hence modulo s^{n(μ)+1},

     c_{λμ} ≡ t^{−n(λ')} A_{λμ'}(0) s^{n(μ)} t^{n(μ')} B_{μ'μ}(0) = s^{n(μ)} t^{n(μ')−n(λ')} a^{HL}_{λμ'}(τ).

   - Lemma 3 turns this into the Kostka sum. Use t^{n(μ')−n(λ')}K_{ρμ'}(1/t) = t^{n(ρ)−n(λ')}K̃_{ρμ'}(t).
   - **No cancellation is possible.** The minimal s-order is reached by exactly one ν, so Clio's worry about cancellation does not arise at the diagonal.
5. **(D).**
   - Every term t^{n(ρ)−n(λ')}K̃_{ρμ'}(t) is a polynomial, since n(ρ) ≥ n(λ') whenever K_{ρ'λ} ≠ 0.
   - It has a nonzero constant term only when ρ = λ'. There the constant term is K̃_{λ'μ'}(0) = lead coefficient of K_{λ'μ'} = 1 (Lemma 3(b)), and K_{λλ} = 1. So d(0) = 1.
   - Alternatively, the nonvanishing of d already follows from Lemma 3(a) at τ = 0 (t = ∞), with no degree facts needed: a^{HL}_{λμ'}(0) = K_{μλ} > 0.
   - d(1) = Σ_ρ K_{ρμ'}K_{ρ'λ} = ⟨h_{μ'}, e_λ⟩ = M_{λμ'} (Macdonald I (6.6)).
6. **(V).**
   - P_ν(x;q,τ) is regular at q = 1 and P_ν(x;1,τ) = e_{ν'} (Macdonald VI (4.14)(vi); regularity at s = 1 via integrality of J_ν, VI §8, locator not re-verified). Then B(1) is the permutation matrix ν ↦ ν', and A(1) is its inverse. At s = 1, T_ν = t^{n(ν)}.
   - So c(1) = t^{−n(λ')} t^{n(λ')} δ = δ. ∎

**Operator form (Op-DS), support and lead.** The same argument applied to E_k e_μ = t^{−C(k,2)}𝒩 e_k 𝒩^{−1} e_μ gives the support and lead of Op-DS:
- 𝒩^{−1}e_μ ∈ span{P_ν : ν ⊴ μ'}.
- e_kP_ν ∈ span{P_κ : κ ⊴ ν + 1^k ⊴ (μ∪k)'}, by Macdonald Pieri (VI (6.24)), or simply by monomial triangularity. Its P_{(μ∪k)'} coefficient is 1 and comes from ν = μ' alone.
- So the support is {ρ ⊵ μ∪k}, and the lead is t^{−C(k,2)}T_{(μ∪k)'}/T_{μ'} = s^{n(μ∪k)−n(μ)} = s^{Σ_i min(μ_i,k)}, because n((μ∪k)') − n(μ') = C(k,2).
- Not checked separately by script. The Day 214 Op-DS check covers the statement itself.

## 4. Gaps and caveats

1. **Grade inheritance.** Everything here inherits the grade of (N), which is proved modulo the Cherednik facts (C1)–(C3) (textbook, locators unverified) and 207b's (A_k)/(K_k). By contrast, Day 214's proof of DS uses only 207b and elementary degree counts. So the Day 214 proof is the *more elementary* one. This note is a second proof plus a structural explanation, not a replacement.
2. **Polynomiality is not explained.** (N) yields c_{λμ} ∈ ℚ(t)(s) ∩ s^{n(μ)}ℛ. The cancellation of Macdonald denominators (1 − s^{a+1}τ^l) needed for c ∈ ℚ[s,t] is invisible from (N). It is a genuine extra fact, supplied by the Gauss-lemma argument of Day 214.
3. **Textbook locators not re-verified this session:**
   - VI (7.13′) (regularity at q = 0);
   - VI (4.14)(iii),(vi) (q = 0 and q = 1 specialisations);
   - III §6–7 (Kostka–Foulkes degree/monic/charge; Hall-duality of Q′);
   - integrality of J for q = 1 regularity.

   All are standard. The script checks their consequences for n ≤ 4 (n = 5 pending), though not the statements themselves in general.
4. **Computed-only range.** The verification is n ≤ 4 (symbolic, full check set); n = 5 is pending (first run truncated, rerun in progress as of 2026-10-03). n = 6 was not run, because Gram–Schmidt over ℚ(q,T) is slow.
5. **Novelty.** The d-formula d_{λμ}(t) = Σ_ρ t^{n(ρ)−n(λ')}K̃_{ρμ'}(t)K_{ρ'λ} is the Day 215 "d = HL/cocharge t-count" statement, now *derived* rather than observed. It is a product of a cocharge-Kostka matrix and a Kostka matrix, i.e. ⟨e_λ, ·⟩ applied to a modified HL function. Expect it to be folklore-adjacent once (N) is known.
