## 1. Statement

**Theorem (C1).** Y_iY_j = Y_jY_i on Pol for all i, j.

**Theorem (B).** Define two orders on compositions of the same size d:
- **Dominance.** For partitions, ν' ⊴ ν means the partial sums of ν' are ≤ those of ν.
- **Composition order.** For compositions, μ ≤_c λ means P_q(μ) ≤ P_q(λ) for all q, where P_q(μ) := μ_1+⋯+μ_q.

Define the strict partial order ≺ by: μ ≺ λ iff either
- μ^+ ◁ λ^+ (strictly lower in dominance; μ^+ is the decreasing rearrangement), or
- μ^+ = λ^+, μ ≠ λ, and μ ≤_c λ.

Then for every i and λ,

  Y_i x^λ = s^{λ_i} t^{b_i(λ)} x^λ + Σ_{μ ≺ λ} c_{μ} x^μ,  where b_i(λ) = #{j : λ_j > λ_i} + #{j < i : λ_j = λ_i}.

**Corollary (C3).** On each Pol_d the Y_i are simultaneously diagonalisable over K with simple joint spectrum. The eigenbasis is E_λ = x^λ + Σ_{μ≺λ}(…), with eigenvalues y_i(λ) = s^{λ_i}t^{b_i(λ)}, and b(λ) is a permutation of (0,…,m−1).

On the order: Wake 233 observed "λ^+ dominance, then more inversions = lower" (tri_check). Here we use composition dominance P_q instead, because it is exactly what the proof controls. Within an orbit it puts the decreasing rearrangement on top, as before.

### 2.2 Haiman's π for GL_m, and its conjugation direction (derived, not quoted)

Take n = m and Y = ℤ^m. The alcove is A_0 = {x : x_1 ≥ x_2 ≥ ⋯ ≥ x_m ≥ x_1 − 1}, since α_0 = δ − θ and θ = e_1 − e_m. The translations act by y^λ(x) = x + λ, and W_0 = S_m acts linearly.

**Finding π.** Ω ≅ Y/Q_0 ≅ ℤ by the coordinate sum (Cor 3.12). It is generated by the π with minuscule λ_π = e_1. Let v be the m-cycle e_j ↦ e_{j+1} (indices mod m), so (vx)_j = x_{j−1}. Then

  y^{e_1}v(x) = (x_m + 1, x_1, …, x_{m−1}),

and this satisfies x_m+1 ≥ x_1 ≥ ⋯ ≥ x_{m−1} ≥ x_m = (x_m+1) − 1. So y^{e_1}v maps A_0 to A_0, hence π = y^{e_1}v and v_π = v.

**Reduced word for v_π.**
- s_1s_2⋯s_{m−1} sends e_1 ↦ e_2. Here s_{m−1},…,s_2 fix e_1, then s_1 acts.
- It sends e_m ↦ e_{m−1} ↦ ⋯ ↦ e_1.
- So v_π = s_1⋯s_{m−1} and v_π^{-1} = s_{m−1}⋯s_1. This word is reduced: v_π^{-1} (j ↦ j−1, 1 ↦ m) has one-line form (m,1,2,…,m−1), whose inversions are exactly the m−1 pairs involving m, so its length is m−1.
- Hence T_{v_π^{-1}} = T_{m−1}⋯T_1, and

  **Φ(y^{e_1}) = π T_{m−1}⋯T_1.**

**Conjugation direction.**
- For 1 ≤ i ≤ m−2: πs_iπ^{-1} = y^{e_1}(v s_i v^{-1})y^{−e_1} = y^{e_1}s_{i+1}y^{−e_1} = s_{i+1}, since s_{i+1} fixes e_1.
- For i = m−1: v s_{m−1}v^{-1} = s_φ with φ = e_1 − e_m. Then πs_{m−1}π^{-1} = y^{e_1}s_φ y^{−e_1} = y^{e_1 − e_m}s_φ = y^φ s_φ = s_0 (§3.5, (14)).
- Since π permutes S, it also sends s_0 ↦ s_1.

So in B(W_e) we have **πT_iπ^{-1} = T_{i+1} (indices mod m)**. This is the SAME direction as ours (relation (c) below), so no π ↦ π^{-1} swap is needed. This answers the PROVE.md CHECK.

**The other generators.** Relation (9) with λ = e_j gives T_j^{-1}y^{e_j}T_j^{-1} = y^{e_{j+1}}, since ⟨e_j, e_j − e_{j+1}⟩ = 1 and s_je_j = e_{j+1}. By induction on i,

  Φ(y^{e_i}) = T_{i−1}^{-1}⋯T_1^{-1} · πT_{m−1}⋯T_1 · T_1^{-1}⋯T_{i−1}^{-1} = T_{i−1}^{-1}⋯T_1^{-1} π T_{m−1}⋯T_i.

### 2.3 The dictionary

**Lemma 2.3.** Let ι be the map on generators T_j ↦ T_j^{-1} (j = 0,…,m−1), π ↦ π. It extends to an automorphism of B(W_e), and

  ι(Φ(y^{e_i})) = W_i := T_{i−1}⋯T_1 π T_{m−1}^{-1}⋯T_i^{-1}.

*Proof.*
- The braid relations are preserved by ι. If ABA = BAB, then A^{-1}B^{-1}A^{-1} = (ABA)^{-1} = (BAB)^{-1} = B^{-1}A^{-1}B^{-1}. Commutations are preserved in the same way. This is Haiman §2.7.
- The relation πT_jπ^{-1} = T_{j+1} becomes πT_j^{-1}π^{-1} = T_{j+1}^{-1}, which still holds.
- So ι respects all defining relations of Ω ⋉ B(W_a). Since ι is an involution, it is an automorphism.
- The formula for W_i is then immediate from §2.2. ∎

**Consistency check.** ι applied to relation (9) gives W_{j+1} = T_jW_jT_j. Since Y_i = t^{m−i}ρ(W_i), this is exactly (B2) Y_{j+1} = t^{-1}T_jY_jT_j of 216b.

**Corollary 2.4.** The W_i commute pairwise in B(W_e). The reason: the y^{e_i} commute in B(Y,W_0), Φ is an isomorphism, and ι is an automorphism.

## 3. (B): triangularity, by hand

### 3.1 T on monomials (two variables; others are spectators)

Write (a,b) for the exponents of (X_i, X_{i+1}), and let B(a,b) := Σ_{min<c<max} x^{(c, a+b−c)} be the "between" terms. Then:

| case | T_i x^{(a,b)} | T_i^{-1} x^{(a,b)} |
|---|---|---|
| a > b | x^{(b,a)} + (1−t)B | t^{-1}x^{(b,a)} − (1−t^{-1})x^{(a,b)} + t^{-1}(1−t)B |
| a < b | t x^{(b,a)} + (t−1)x^{(a,b)} + (t−1)B | x^{(b,a)} + (1−t^{-1})B |
| a = b | t x^{(a,a)} | t^{-1}x^{(a,a)} |

*Derivation.*
- Case a > b. s_iF − F = −x^by^b(x^{a−b} − y^{a−b}), and dividing by x − y gives −Σ_{k=0}^{a−b−1}x^{b+k}y^{a−1−k}. Multiplying by y and adding t·x^by^a gives the first row.
- Case a < b. s_iF − F = x^ay^a(x^{b−a} − y^{b−a}), and the same steps apply.
- T^{-1} = t^{-1}(T − (t−1)).
- Machine check: log line 1, all a,b ≤ 5.

### 3.2 The dominance filtration

**Lemma 3.2.** If b < c < a, then the decreasing rearrangement of the composition obtained by replacing the entries (a,b) at two positions with (c, a+b−c) is strictly dominated by the old rearrangement.

*Proof.*
- P_k(v^+) = max_{|S|=k} Σ_{p∈S} v_p.
- Take a k-subset S. If S contains both changed positions or neither, its sum is unchanged.
- If S contains exactly one of them, the new value there is < a. Swapping that position for the position of a gives a k-subset whose old sum is ≥ the new sum of S.
- So each new partial maximum is ≤ the old one. The multisets differ, so the inequality is strict somewhere. ∎

**Consequence.** Let F_ν := span{x^μ : μ^+ ⊴ ν} and F_{◁ν} := span{x^μ : μ^+ ◁ ν}.
- T_j and T_j^{-1} preserve both spaces: by §3.1 they send x^μ into span{x^μ, x^{s_jμ}} + F_{◁μ^+}.
- π permutes exponents and rescales, so it preserves both spaces too.

So every Y_i acts on gr_ν := F_ν/F_{◁ν}, which has basis the x^μ with μ^+ = ν. On gr_ν the between terms vanish:

- **T_j^{-1} on gr.** If (p,q) is the pair at positions j, j+1:
  - p<q: swap only, coefficient 1.
  - p=q: scalar t^{-1}.
  - p>q: swap with coefficient t^{-1}, plus stay with coefficient −(1−t^{-1}).
- **T_j on gr.**
  - p>q: swap only, coefficient 1.
  - p=q: scalar t.
  - p<q: swap with coefficient t, plus stay with coefficient (t−1).
- **π on gr.** Rotation μ ↦ (μ_m, μ_1, …, μ_{m−1}), with factor s^{μ_m}.

In the case p = q, "swap" and "stay" are the same composition, so we call it a swap.

### 3.3 Path expansion of Y_i x^λ on gr_ν

Expand Y_i x^λ on gr_ν as a sum over paths. At each binary step a path chooses "swap" or (where allowed) "stay". Track the **carried entry**, meaning the entry at the active position.

**Phase 1** (T_i^{-1}, …, T_{m−1}^{-1}).
- Before step j the active position is j. It holds the carried value w_j, and w_i = a := λ_i.
- Position j+1 still holds the untouched λ_{j+1}.
- Swap: the deposit at j is D_j = λ_{j+1}, and w_{j+1} = w_j.
- Stay (allowed only if w_j > λ_{j+1}): D_j = w_j, and w_{j+1} = λ_{j+1} < w_j.
- In both cases **D_j + w_{j+1} = w_j + λ_{j+1}**, and **w is non-increasing**.
- Set e := w_m.

**π.** Position m goes to position 1 with factor s^e, and everything else shifts right by one.

**Phase 2** (T_1, …, T_{i−1}).
- Before step j the active position is j, holding u_j, with u_1 = e.
- Position j+1 holds λ_j, untouched by phase 1 and shifted by π.
- Swap: the deposit is g_j = λ_j, and u_{j+1} = u_j.
- Stay (allowed only if u_j < λ_j): g_j = u_j, and u_{j+1} = λ_j > u_j.
- In both cases **g_j + u_{j+1} = u_j + λ_j**, and **u is non-decreasing**.
- Set f := u_i.

**The output composition** of a path is μ = (g_1, …, g_{i−1}, f, D_i, …, D_{m−1}).

**Lemma 3.3.** For every path, P_q(μ) ≤ P_q(λ) for all q. Equality for all q holds only on the all-swap path, and that path outputs μ = λ.

*Proof.*
- **q ≤ i−1.** Telescoping the phase-2 identity gives P_q(μ) = Σ_{j≤q}(u_j + λ_j − u_{j+1}) = P_q(λ) − (u_{q+1} − e). This is ≤ P_q(λ) because u is non-decreasing from u_1 = e.
- **q ≥ i.** Telescoping the phase-1 identity over j = q..m−1 gives the tail sum Σ_{j=q}^{m−1}D_j = Σ_{p>q}λ_p + (w_q − e). Since |μ| = |λ|, P_q(μ) = P_q(λ) − (w_q − e) ≤ P_q(λ).
- **Equality.** If all partial sums are equal, then u ≡ e and w ≡ e. Every stay strictly changes the carried value, so no stay occurred.
- **The all-swap path.** a is carried from position i to m, rotated to position 1, and carried back to i. The entries λ_{i+1..m} shift left and back, and λ_{1..i−1} shift right and back. So μ = λ. ∎

**Coefficient of the all-swap path.** It is t^{m−i}·s^a times:
- from phase 1: ∏_{j>i}(1 if a<λ_j; t^{-1} if a ≥ λ_j);
- from phase 2: ∏_{j<i}(1 if a>λ_j; t if a ≤ λ_j).

The resulting t-exponent is

  (m−i) − #{j>i : λ_j ≤ a} + #{j<i : λ_j ≥ a} = #{j>i : λ_j > a} + #{j<i : λ_j ≥ a} = b_i(λ).

**Proof of Theorem (B).**
- In gr_{λ^+}, Lemma 3.3 says that every non-all-swap path ends at some μ ≠ λ with μ ≤_c λ.
- The all-swap path alone contributes to x^λ, with coefficient s^{λ_i}t^{b_i(λ)}. Cancellations among paths can only shrink the support.
- Lifting from gr_{λ^+} to F_{λ^+} adds terms in F_{◁λ^+}, all of which are ≺ λ. ∎

**b(λ) is a permutation.** Rank the indices by "larger λ_j first, ties broken by smaller j". Then b_i(λ) is the number of indices ranked strictly before i, i.e. i's rank minus 1.

### 3.4 Proof of Corollary (C3)

**Distinct joint eigenvalues.** If λ ≠ λ' with |λ| = |λ'| = d, then y(λ) ≠ y(λ'). The s-degree of y_i(λ) is λ_i, and s, t are independent.

**A separating operator.** Choose c ∈ ℚ so that z(λ) := Σ_i c^{i−1}y_i(λ) are distinct over the finitely many λ ⊢_comp d. Each pair λ ≠ λ' excludes the at most m−1 roots of a nonzero polynomial in c. Set Z := Σ c^{i−1}Y_i.

**Diagonalising.**
- Z is triangular in a linear extension of ≺ on Pol_d, with distinct diagonal entries z(λ). So Z is diagonalisable, with 1-dimensional eigenspaces K·E_λ and E_λ = x^λ + Σ_{μ≺λ}(…).
- Each Y_i commutes with Z by (C1), so it preserves each line K·E_λ.
- The eigenvalue of Y_i on E_λ is the coefficient of x^λ in Y_iE_λ, which is y_i(λ) by (B).

So the Y_i are simultaneously diagonal in {E_λ} with simple joint spectrum (y_i(λ)) = (s^{λ_i}t^{b_i(λ)}). This is exactly the statement (C3) used in 216b §9.1–9.4. ∎
